## Edge Cases

### Events Not Firing

This case may happen when deploying on a new analytics deployment. This case is usually bad. Only thing to note here is to pretty much not ever leave the current analytics deployment because the website cache is hitting the older data and we would need the user to accept the new cookies coming in.
